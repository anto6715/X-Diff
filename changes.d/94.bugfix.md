`xdiff files` and `xdiff dirs` now check both files in full when no `-v` is given, and compare text and non-standard calendar dates, so more file pairs fail than before. Until now only the reference file's data variables and dimension coordinates were compared, and text was skipped. These are new:
- A variable found in only one of the two files fails as `Only in the reference file` or `Only in the comparison file`, and a dimension as `Dimension only in the reference file` or `Dimension only in the comparison file`. A variable that exists only in the comparison file used to pass unnoticed.
- Auxiliary coordinates, such as NEMO's 2-D `nav_lon`/`nav_lat`, are compared like data variables. Two files that differed only in them used to pass.
- A dimension without a coordinate variable gets its own row, which compares its size (`size only`).
- Text variables, and dates in a non-standard calendar such as `noleap` or `360_day`, are compared for equality, also when named with `-v`; a failing row says how many values differ. They used to be skipped, so two files whose `noleap` time axis differed still passed.
- A variable that holds text in one file and numbers in the other fails as a data type mismatch. It used to pass when the text was in the reference file.

Attributes are still not compared. `xdiff plot` is unchanged.
