`xdiffly[plot]` now requires holoviews 1.19.1 and datashader 0.17.0 or newer. holoviews 1.19.0 and datashader releases before 0.17 import `dask.dataframe` when they load, which needs pyarrow from dask 2025.1 on. With them and a newer dask without pyarrow, `xdiff plot` served an error page instead of the dashboard. A fresh install normally picks newer releases. The problem showed up when xdiffly was installed into an environment that already had the old ones.
