A variable named with `-v` that a file does not have now fails instead of being dropped, so more runs fail than before. Until now `-v sst -v typo` passed on `sst` alone, and so did a name found only in the comparison file. These are new:
- A `-v` name missing from a file fails as `Not in the reference file`, `Not in the comparison file` or `Not in either file`. A name missing from the comparison file already failed, but with xarray's error text.
- A `-v` name that is a dimension without a coordinate variable is compared by size, as without `-v`. It used to be dropped. With `--last-time-step`, a time dimension named this way fails, as a time coordinate does.
- In `xdiff dirs`, `-v` applies to every file pair, so a variable missing from a pair fails that pair. To check variables kept in different files (`grid_T`, `grid_U`), run once per `--filter`.
- `xdiff plot -o` lists each `-v` name it cannot plot as `skipped`: one missing from a file, a dimension without values, or a text or non-standard calendar variable. A name missing from the reference file, and text, used to be left out without a word.
