`xdiff plot` can be started again on the same port right after Ctrl-C. Until now it was refused as "already in use" for about a minute, while the browser connections the stopped server had closed were still in TCP `TIME-WAIT`. A port another server is listening on is still refused, with the same message; on macOS, a server listening on all addresses (`0.0.0.0`) no longer blocks it, since the live server can bind `localhost` beside it. When `localhost` also resolves to IPv6 (`::1`), a server on that address is now reported at once, instead of the live server failing after the files are opened.
