The report now prints file paths, variable names and failure messages exactly as written. Rich used to read parts of them as formatting codes:
- A `[/...]` in a path or message, such as a directory `run[` with a subdirectory `b]`, stopped the report with a traceback at the first table showing it: that table, the ones after it, the list of failed comparisons and the summary were not printed. In a terminal, the progress line stopped the run at the first such file.
- Bracketed text such as `[s]` or `[degC]` was dropped: a data type mismatch between `timedelta64[s]` and `timedelta64[ns]` printed as `timedelta64` twice, and a variable `temp[degC]` as `temp`.
- A code such as `:x:` in a name was turned into an emoji.
