The live `xdiff plot` server redraws much faster. On MedFS files a depth change drops from about 2.7 s to under 0.1 s: a variable stored as one compressed block is decompressed once instead of on every change, the reference/comparison maps are built only when their card is opened, images are sent as 32-bit floats, and datashader is warmed up in the background when the server starts.
