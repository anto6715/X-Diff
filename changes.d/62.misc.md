Remove unused public names. The CLI behaves the same; code that imports `xdiff` as a library is affected only if it used one of these: the settings `xdiff.conf.DEFAULT_MAXDEPTH`, `DTYPE_NOT_CHECKED`, `TIME_DTYPE` and `LOGGING_CONFIG`; the module `xdiff.utils.module_loading`; `xdiff.utils.regex.find_file_matches`; `Comparison.set_exception`; the constants `xdiff.model.compare_result.PASSED` / `FAILED`; and the `get_version` keyword of `xdiff.core.execute`. `configure_logging` now takes only the logging settings, which must be a `logging.config.dictConfig` dictionary, and xdiff's default logging setup can no longer be switched off or replaced through `LOGGING_CONFIG`. Callers of the legacy `xdiff.compare.compare` that relied on `find_file_matches` now build its `{reference_path: [comparison_paths]}` argument themselves.
