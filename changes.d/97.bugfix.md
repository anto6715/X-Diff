Boolean variables are compared again. Two identical ones used to fail with numpy's "boolean subtract is not supported", so the run exited 1. They are now compared for equality, like text: a row says `equality only` or how many values differ. `xdiff plot` draws them as a -1/0/1 map of the flags that differ.

A `--bbox` crop on a curvilinear grid (for example NEMO `nav_lon`/`nav_lat`) now keeps every variable's data type, so some file pairs fail that used to pass:
- Integers, booleans and text are no longer turned into floats or object arrays. They are compared over the smallest index rectangle that holds the box; only floating-point fields are masked outside the box.
- An integer or boolean field against a float field of the same values now fails as a data type mismatch. It used to pass.
- Variables that are not on the grid, such as time bounds, are no longer broadcast onto it. This lowers memory use.
