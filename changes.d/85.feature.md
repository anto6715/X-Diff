The live `xdiff plot` server keeps the map's zoom and pan when you change time or depth, toggle smooth/blocks, turn a basemap on or off, or switch to another variable on the same grid; Reset returns to the area that holds data at the current level. Once the first page has loaded, datashader is also warmed up for zoomed views and basemaps, so the first zoom and the first basemap after the server starts no longer wait about half a second.
