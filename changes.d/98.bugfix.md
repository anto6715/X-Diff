`xdiff dirs` now fails on a file found only in the comparison directory, so more runs fail than before. Such a file used to be ignored, and two directories that differed only by it passed.
- It fails as `Only in the comparison directory`, labelled `ONLY IN COMPARISON`, when the pairing described under #101 leaves it without a counterpart.
- A file found only in the reference directory, which already failed, now reads `Only in the reference directory` and is labelled `ONLY IN REFERENCE` instead of `NO MATCH`.
- An empty reference directory now reports each comparison file as `ONLY IN COMPARISON` with status `FAILED`, instead of `NO COMPARISONS`. The exit code is 1 either way.
- If the extra files are expected, narrow the run with `--filter`.
