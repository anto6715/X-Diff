The relative error in the report is now relative to the reference: the largest `|reference - comparison| / |reference|` among the points that differ. It used to divide by the comparison file, so the reported numbers change.
- A difference where the reference is `0` shows `inf`. Such points used to be left out.
- Dates have no relative error: they show `nan` when they differ and `0` when identical. They used to get a number with no meaning.
- Two identical fields holding only zeros and missing values (such as land) now pass. They used to get `nan` and fail.

Pass/fail is otherwise unchanged. On large files the run is faster and uses less memory, since only the points that differ are divided.
